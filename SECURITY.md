# Politique de sécurité

## Versions prises en charge

NutriCoach est en phase initiale de développement. Seule la branche `main` actuelle est examinée pour les correctifs de sécurité ; aucune version stable n'est encore publiée.

## Signaler une vulnérabilité

Utilisez le signalement privé de vulnérabilité GitHub du dépôt. Ne créez pas d'issue publique pour une faille de sécurité.

Le rapport doit contenir uniquement les informations techniques minimales permettant de reproduire le problème. Ne joignez jamais de donnée personnelle, donnée de santé, clé API, token, mot de passe ou autre secret réel.

Le titulaire du projet analysera le signalement et pourra demander des précisions. Aucun délai contractuel de réponse ou de correction n'est garanti pendant cette phase de développement.
