# Contributions

Merci de l'intérêt porté à NutriCoach.

## Signalements

Les signalements de bogues et suggestions peuvent être déposés dans les issues GitHub, à condition de ne contenir aucune donnée personnelle, donnée de santé, clé, token ou autre information confidentielle.

Les vulnérabilités suivent exclusivement la procédure privée décrite dans [SECURITY.md](SECURITY.md).

## Contributions de code ou de contenu

Le projet n'accepte pas automatiquement les contributions externes pour le moment. Cette règle protège la chaîne de propriété intellectuelle et la possibilité de proposer ultérieurement une licence commerciale distincte.

Toute personne intéressée pour travailler sur le projet peut contacter Valentin GIDON à l'adresse [nodig63@gmail.com](mailto:nodig63@gmail.com) afin d'échanger sur une collaboration avant de préparer une contribution.

Avant d'ouvrir une pull request contenant du code, de la documentation, un design, une image, des données ou tout autre contenu protégeable :

1. obtenir l'accord écrit préalable de Valentin GIDON ;
2. confirmer que la contribution est originale ou correctement autorisée ;
3. déclarer toutes les sources et licences tierces ;
4. signer, si cela est demandé, un accord de contribution permettant la distribution open source et une éventuelle double licence commerciale.

Une pull request non sollicitée peut être fermée sans être fusionnée. Le simple dépôt d'une proposition ne transfère pas automatiquement au projet tous les droits nécessaires à une future double licence.

## Éléments interdits

Ne jamais proposer :

- un contenu copié sans autorisation ou attribution ;
- un élément sous une licence incompatible avec `AGPL-3.0-only` ;
- une donnée personnelle ou médicale réelle ;
- une clé API, un token, un mot de passe ou un fichier de signature ;
- un composant dont l'origine ou les conditions d'utilisation sont inconnues.
